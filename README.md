# E-Commerce Sales Analysis – SQL

## 📌 Project Overview

This project analyzes an e-commerce sales dataset using SQL to identify key business insights related to sales performance, products, customers, stores, geography, sales channels, and time-based trends.

The goal is to demonstrate practical SQL skills for data cleaning, analysis, aggregation, filtering, joins, and business-oriented problem solving.

## 🛠️ Tools & Technologies

- MySQL
- SQL

- Top-selling products
- Product categories by units sold
- Monthly sales volume

- Top 5 products by revenue

- Most profitable product category

### Customer Analysis

### Geographic Analysis

### Store Analysis
- Highest-revenue store
